Pre-trained Models Used

Model Provider Role in ClimaGuard License / Terms
Gemini 2.5 Flash Google Primary model — text generation, function calling, multi-turn health chat, multimodal vision; UI & offline-guide translation; audio-transcription fallback Google Gemini API Terms (commercial hosted API, pre-trained)
gpt-4o-transcribe OpenAI Primary speech-to-text (the model behind ChatGPT voice) for multilingual voice input OpenAI API Terms (commercial hosted API, pre-trained)
GPT-4o OpenAI Fallback for text & vision when all Gemini keys are rate-limited/unavailable OpenAI API Terms (commercial hosted API, pre-trained)
Browser Web Speech API Device / OS On-device text-to-speech for read-aloud (works offline) Native browser API; device TTS voices

No models were trained or fine-tuned from scratch. All are used as pre-trained foundation models via official hosted APIs, called server-side only (keys never exposed to the client). API usage costs are borne by the team. Reliability is handled by a multi-provider chain: three Gemini keys → OpenAI GPT-4o.

No third-party training datasets are used. The system reasons over live API data, not a trained dataset. Photos submitted for vision analysis are processed in real time and not persisted.

Known Limitations & Ethical Considerations

  • Not medical advice. ClimaGuard is a humanitarian first-response aid, not a diagnostic tool; this is stated in-product, and users are directed to professional care and local emergency services.
  • AI uncertainty. Text guidance and single-photo vision triage can be wrong; outputs are framed as first-response suggestions, never clinical conclusions, and always include escalation (“go to hospital if…”).
  • Language & translation variance. Output quality depends on the model’s per-language strength; low-resource languages may be less reliable, and AI-translated UI/guidance may contain wording errors — mitigated by 23 hand-authored UI languages and English fallback.
  • Emergency-number accuracy. Helplines are curated public values correct at time of curation; users are prompted to verify locally, with 112 as a universal GSM fallback.
  • Privacy. Anonymous authentication only — no names or accounts. Reports are minimized to what powers guidance and the aggregate heatmap; photos are not stored.
  • Bias & safety. Prompts use humanitarian, age-appropriate framing; the vision route detects model safety refusals (e.g. on imagery of minors) and falls back to text-only triage rather than failing silently.
  • Data currency & connectivity. Live features need internet; offline mode preserves the last cached report, the bundled first-aid guide, and tap-to-call helplines.
